# Snake Arena v19

## Что нового (v19)
- **Режим «Без стен» (и «Призрак»):** змейка больше не рисуется линией через всё поле при переходе через край — она плавно выходит с одной стороны и одновременно появляется с противоположной.
- **Скорость растёт с длиной змеи:** плавная кривая 120 мс/ход на старте → ~102 на 24 сегментах → ~91 на 44 → предел 75 мс (`SPEED_START`/`SPEED_MIN` в `index.html`).
- **Рейтинг:** вместо буквы показывается голова змейки в скине игрока (`/api/leaderboard` теперь отдаёт `skin`).

## Что нового (v18)
- **Рефералы починены:** ссылка теперь `t.me/<бот>?start=ref_<id>` — работает с любым ботом. Друг жмёт START, бот засчитывает приглашение (+500 🪙 тебе, +200 🪙 ему), пишет тебе в чат и даёт кнопку «Играть». В профиле появился список «Мои друзья».
  Если у бота настроено основное Mini App, можно `REF_MODE=startapp`; если есть короткое имя приложения — `APP_SHORT_NAME`.
  Реферал засчитывается только новому игроку (кто уже играл — не считается).
- **Комбо — настоящий множитель очков:** яблоки подряд (окно 40 ходов) дают ×2, ×3 … до ×5; бонус 💎 умножает ещё раз. Есть полоска таймера комбо.
- **Плавное управление:** поворот срабатывает сразу, углы змейки скруглены, голова плавно доворачивается; скорость растёт от съеденного, а не от очков.

## v17

- **Скины:** 4 эпических (Радуга, Галактика, Дракон, Алмаз — с анимацией и эффектами) за ⭐ Telegram Stars и 9 обычных за монеты.
- **Бонусы на поле:** ⏳ замедление, 💎 ×2 очки, 👻 призрак (проход сквозь стены и себя).
- **Режим «Без стен»:** награда ×0.5, не идёт в рейтинг (отдельный рекорд).
- **Проверка забега:** сервер выдаёт подписанный токен при старте и сверяет очки с реальным временем.
- **Напоминания:** вечером бот пишет тем, кто рискует потерять серию.

### Как включить оплату Stars
1. `BOT_TOKEN` и `BOT_USERNAME` заданы, `PUBLIC_URL` (или `RENDER_EXTERNAL_URL` на Render) указывает на твой сервис.
2. При запуске сервер сам вызывает `setWebhook`; в логе должно быть `Telegram webhook set`.
3. Скин выдаётся вебхуком после `successful_payment`. Цены Stars — в `SKIN_CATALOG` в `server.js`.
4. Если у бота был другой вебхук/long polling — он будет заменён.

- Рабочие задания дня (прогресс на сервере, кнопка «Забрать»), рейтинг с твоим местом, звуки (WebAudio, кнопка 🔊), плавное движение змейки, новый дизайн.
- Змейка растёт постепенно: +1 сегмент за ход после еды (звезда даёт +3), без лимита длины.
- Рефералы: ссылка `t.me/<бот>?startapp=ref_<id>` приходит с сервера; друг, впервые открывший игру по ссылке, засчитывается один раз (+500 🪙 пригласившему, +200 🪙 другу).
- Управление на телефоне: свайп в любом месте экрана срабатывает сразу, можно делать серию поворотов не отрывая палец; опциональные экранные кнопки (🎮).

- Ежедневная награда: 7 дней с растущей наградой (100…2000 🪙), серия сбрасывается на 1-й день при пропуске. Часовой пояс — `DAILY_TZ`.
- Съеденное яблоко теперь «проезжает» по телу змейки комком и приводит к росту на хвосте.

## Настройка рефералов
Обязательно `BOT_USERNAME`. Если у Mini App есть короткое имя (BotFather → /newapp), укажи `APP_SHORT_NAME` — ссылка станет `t.me/bot/app?startapp=ref_ID`.

## Run
npm install
npm start

Переменные: `DATABASE_URL`, `BOT_TOKEN`, `BOT_USERNAME`.
