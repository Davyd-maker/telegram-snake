# Snake Arena v29

## Что нового в v29 — режим «Уровни»
- 30 уровней в 3 главах: 🌿 Сад, 🗝️ Подземелье, 🌋 Вулкан. Набери цель по очкам — на поле открывается норка, заползи в неё, чтобы пройти уровень.
- Сложность растёт: стены и коридоры → «живые» камни → ворота, которые закрываются по таймеру (мигают перед закрытием); змейка быстрее. Уровни 10, 20, 30 — финалы глав.
- До 3 ⭐ за скорость прохождения; рейтинг по звёздам. Монеты за первое прохождение и за каждую новую звезду, скин за каждую главу. Все уровни бесплатные, открываются по порядку.
- При повторе уровня рядом едет призрак своего лучшего прохождения. Прохождение проверяется сервером, как обычные забеги.
- Раскладки уровней — `LEVELS` в `public/engine.js`; награды — `CHAPTERS`, `levelFirstReward`, `levelStarReward` в `src/catalog.js`. Тесты проверяют, что каждый уровень проходим (`tests/levelbot.js`).
- Магнит переделан: тянет еду на клетку перед головой и только спереди; еда плавно подъезжает. Старые реплеи переигрываются по прежним правилам.

## Как устроен код
- `server.js` — точка входа. Сервер — в `src/`: `routes/` (эндпоинты: игрок, игра, рейтинги, кланы, соцчасть, платежи, админка), `bot.js` (вебхук и рассылки), `jobs.js` (фоновые задачи), `notify.js` (сообщения игрокам и админу), `i18n.js` (тексты бота RU/EN), `missions.js`, `pass.js`, `events.js` (события, турнир), `anticheat.js`, `payments.js`, `seasons.js`, `players.js`, `catalog.js` (все цены и награды), `replay.js`, `db.js` + `migrations.js`, `config.js`, `auth.js`, `middleware.js`, `ratelimit.js`.
- `public/engine.js` — **правила игры, один файл для клиента и сервера**. Клиент играет по нему, сервер по нему же переигрывает забег. В нём нельзя использовать `Math.random()`/`Date.now()`: вся случайность — через seed.
- Клиент: `public/index.html` (разметка), `css/app.css`, `js/catalog.js`, `js/i18n.js` (английский), `js/settings.js` (звук, вибрация), `js/render.js` (отрисовка), `js/card.js` (картинка результата), `js/app.js` (интерфейс и игровой цикл). После правок клиента подними `?v=31` в `index.html`, чтобы у игроков не остался старый кэш.
- Админка: `public/admin/index.html`, открывается по `/admin` только для `ADMIN_TELEGRAM_ID`.

### Как включить оплату Stars
1. `BOT_TOKEN` и `BOT_USERNAME` заданы, `PUBLIC_URL` (или `RENDER_EXTERNAL_URL` на Render) указывает на твой сервис.
2. При запуске сервер сам вызывает `setWebhook`; в логе должно быть `Telegram webhook set`.
3. Скин выдаётся вебхуком после `successful_payment`. Цены Stars — в `SKIN_CATALOG` в `server.js`.
4. Если у бота был другой вебхук/long polling — он будет заменён.

- Рабочие задания дня (прогресс на сервере, кнопка «Забрать»), рейтинг с твоим местом, звуки (WebAudio, кнопка 🔊), плавное движение змейки, новый дизайн.
- Змейка растёт постепенно: +1 сегмент за ход после еды (звезда даёт +3), без лимита длины.
- Рефералы: ссылка `t.me/<бот>?startapp=ref_<id>` приходит с сервера; друг, впервые открывший игру по ссылке, засчитывается один раз (+500 🪙 пригласившему, +200 🪙 другу).
- Управление на телефоне: свайп в любом месте экрана срабатывает сразу, можно делать серию поворотов не отрывая палец; опциональные экранные кнопки (🎮).

- Ежедневная награда: 7 дней с растущей наградой (100…2000 🪙), серия сбрасывается на 1-й день при пропуске. Часовой пояс — `DAILY_TZ`.
- Съеденное яблоко теперь «проезжает» по телу змейки комком и приводит к росту на хвосте.
